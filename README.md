# 酷学院课程批量上传 Skill

自动化批量上传视频课程到酷学院管理后台。支持文件夹扫描、智能命名、自动分类、生成上传计划，配合浏览器自动化完成批量发布。

## 功能特性

- 📁 **智能扫描**：自动递归扫描文件夹中的视频文件
- 🏷️ **智能命名**：自动提取课程名 + 六位数日期（如：高效沟通 230301）
- 📂 **自动分类**：根据文件夹结构自动匹配资源分类（销售类/职能类/运营类/产研类/管理类/通识类）
- 📊 **生成上传计划**：输出Excel清单，包含课程名、分类、配套PPT、文件大小等
- 🤖 **浏览器自动化**：配合Browser Use实现批量上传

## 安装方法

### 前置条件
- 已安装豆包办公版
- 已安装Python 3.8+

### 步骤1：下载Skill文件

从GitHub下载仓库：https://github.com/henrybridge004-hub/kuxueyuan-batch-upload

### 步骤2：复制到Skill目录

把 `kuxueyuan-batch-upload` 整个文件夹复制到豆包的 user_skills 目录：

```
C:\Users\<你的用户名>\AppData\Local\DoubaoWork\User Data\Default\.doubaowork\agent_mode\workspace\.user_skills\
```

### 步骤3：重启豆包

重启豆包办公版，Skill会自动加载。

### 步骤4：安装Python依赖

```bash
pip install openpyxl
```

## 使用方法

### 扫描课程文件夹

```bash
python scripts/scan_courses.py --folder "E:\课程文件夹" --output "上传计划.xlsx"
```

### 示例输出

```
🔍 正在扫描文件夹: E:\可复用的文件 乔梁\职能族

📊 找到 34 个视频课程
✅ 上传计划已生成: 职能族上传计划.xlsx
   共 34 个课程
   职能类: 34个
```

## 默认配置

| 配置项 | 默认值 |
|--------|--------|
| 培训分类 | 通用培训 |
| 分派方式 | 自学 |
| 可见范围 | 全公司可见 |

## 命名规则

课程名称 = 课程名 + 六位数日期

示例：
- `有效沟通 桂诗源 230604.mp4` → `有效沟通 桂诗源 230604`
- `青蓝第一天20260910.mp4` → `青蓝第一天 260910`

## 注意事项

- 单个视频文件 ≤ 2G
- 每次最多上传5个课件
- 上传后需要转码，转码时间取决于文件大小
