# 酷学院批量上传工作流

## 前提条件

1. 已登录酷学院管理后台：https://pro.coolcollege.cn/
2. 已生成上传计划Excel清单
3. 视频文件可正常访问

## 浏览器自动化上传步骤

### Step 1: 进入批量发布页面

```
导航到：知识库 → 线上课 → 批量发布课件
URL: https://pro.coolcollege.cn/sub-sys/kuxueyuan-manage/prod/split?eid=xxx#/training/resourceManage/courseManage
点击"批量发布课件"按钮
```

### Step 2: 分批上传

**每批最多5个视频**，按以下流程执行：

#### 2.1 上传视频文件
1. 点击"本地上传"或拖拽区域
2. 选择当前批次的视频文件（最多5个）
3. 等待上传进度条完成

#### 2.2 填写课程信息
每个视频对应一个独立课程，需要填写：

| 字段 | 填写规则 |
|------|--------|
| 课程名称 | 使用生成的课程名（含日期后缀） |
| 课程分类 | 根据上传计划选择对应分类 |
| 可见范围 | 默认：全公司可见 |
| 课程介绍 | 留空或填写简单介绍 |
| 课程封面 | 留空（使用默认封面） |

#### 2.3 上传配套PPT
1. 在课程详情中找到"添加课件"
2. 上传配套的PPT/PDF文件作为讲义
3. 确认文件上传完成

#### 2.4 发布课程
1. 确认所有信息填写完毕
2. 点击"发布"按钮
3. 等待发布成功提示

### Step 3: 等待转码

- 视频上传后需要转码，转码时间取决于文件大小
- 转码期间不要操作其他内容
- 每30秒检查一次转码状态

**转码状态判断：**
- ✅ 完成：课程列表中显示"已发布"
- ⏳ 进行中：显示"转码中"或"处理中"
- ❌ 失败：显示"转码失败"

### Step 4: 进入下一批

当前批次全部转码完成后，开始下一批：
1. 记录已完成的课程
2. 回到批量发布页面
3. 重复Step 2-3的流程

### Step 5: 生成上传报告

全部上传完成后，生成Excel报告：
- 成功上传的课程列表
- 失败的课程及原因
- 待处理的课程（转码中）

## 注意事项

1. **文件大小限制**：单个视频 ≤ 2G
2. **批量数量限制**：每次最多5个课件
3. **网络稳定**：上传过程中保持网络连接稳定
4. **不要并发操作**：上传期间不要同时操作其他功能
5. **定期检查**：每10个课程检查一次转码状态

## 常见问题

**Q: 上传失败怎么办？**
A: 检查文件大小是否超过2G，网络是否稳定，重试1次仍失败则记录错误继续下一批。

**Q: 转码需要多久？**
A: 一般10分钟-30分钟，取决于视频时长和大小。

**Q: 上传后在哪里看？**
A: 知识库 → 线上课 → 已发布列表中查看。
